# Tech Stack

This project is built using the following technologies:

## Core
- **React** (`react`, `react-dom`): UI library
- **TypeScript** (`typescript`): Type safety
- **Vite** (`vite`, `@vitejs/plugin-react`): Build tool and development server

## Routing & State Management
- **React Router** (`react-router-dom`): Routing
- **Zustand** (`zustand`): State management
- **React Query** (`@tanstack/react-query`): Server state management

## UI & Styling
- **Tailwind CSS** (`tailwindcss`, `autoprefixer`, `postcss`): Utility-first CSS framework
- **Radix UI** (`@radix-ui/*`): Unstyled accessible UI components
- **Lucide React** (`lucide-react`): Icons
- **Tailwind Merge** (`tailwind-merge`), **clsx**, **class-variance-authority**: Styling utilities
- **Next Themes** (`next-themes`): Theme management (Dark/Light mode)
- **tailwindcss-animate**: Tailwind CSS animation plugin
- **Sonner** (`sonner`): Toast notifications

## Forms & Validation
- **React Hook Form** (`react-hook-form`): Form handling
- **Zod** (`zod`, `@hookform/resolvers`): Schema validation

## Utilities
- **date-fns**: Date manipulation
- **dnd-kit** (`@dnd-kit/*`): Drag and drop library
- **Recharts** (`recharts`): Data visualization

## Backend & Infrastructure
- **Firebase** (`firebase`): Authentication, Database, and Hosting

## Tools & Linters
- **ESLint** (`eslint`, `@eslint/js`, `eslint-plugin-react-*`): Linter
- **TypeScript ESLint** (`typescript-eslint`): TypeScript specific linting rules
- **Vite PWA Plugin** (`vite-plugin-pwa`): PWA capabilities
